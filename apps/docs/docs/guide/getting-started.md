# 快速上手

AgentWeave 管理这台电脑上的用户级全局资源。CLI 和本地网页共用中央仓库，默认位置是 `~/AgentWeave`。

## 安装与启动

安装 CLI 需要 Node.js 22.13 或更高版本。可以通过 npm 安装并打开网页。

```sh
npm install -g agentweave-cli
agentweave ui
```

本地构建的 npm 安装包也可以用 `npm install -g ./agentweave-cli-0.1.0.tgz` 安装。

浏览器会打开本地管理界面。手动打开时，使用终端显示的地址，默认是 `http://127.0.0.1:10107`。在终端操作时，可以运行 `agentweave init` 开始导入。

从仓库构建安装包的步骤见[开发说明](../development.md)。

## 导入本机资源

1. 打开左侧「本机检查」，AgentWeave 会扫描本机已安装 Agent 的全局配置，并与上次的记录比较。用表格上方的筛选项查看新增、修改、移除和需处理的资源。需要刷新时，点击「重新检查」。
2. 选择 Skills、MCP、全局指令或插件。在表格中展开平台，查看对应资源。平台行的复选框可以批量勾选当前类型，切换类型会保留勾选。不同版本和内置插件请逐项选择。
3. 中央仓库尚无同名资源时，列表默认勾选第一份可选版本。其他同名候选会与已选版本比较。相同版本可合并来源，也可以改选不同的版本。覆盖仓库中的版本需手动勾选。
4. 确认导入后，在「中央仓库」查看已勾选的资源。扫描和导入都会更新本机对比记录，记录也包含未勾选的资源。已导入的资源在本机被移除时，可以预览从中央仓库恢复。

中央仓库文件可在 `~/AgentWeave/codex/` 直接编辑。主指令是 `AGENTS.md`，Skills 和插件分别在 `skills/` 和 `plugins/`，MCP 配置在 `config.toml`。额外指令在 `instructions/`，Codex 无法表达的连接在 `mcp/`。旧 SQLite 仓库会在首次读取时迁移，原数据库保留。

带「内置」标签的插件随平台提供，导入时默认不勾选。需要保存副本时可以手动勾选，CLI 可输入该插件的序号或候选 ID。内置原文件只供查看。部分 Codex 内置插件的安装缓存精简了 Skills，导入时可读取清单和版本一致的随附包。

MCP 用统一格式比较，保留连接方式、启动参数和环境变量等实际差异。差异标签会提示对照来源和不同的字段。点击表格中的「查看原文件」，即可在当前页面查看该 Agent 的原生配置。保存后，AgentWeave 只修改对应服务的原文件，并重新扫描。文件已变化或 TOML 布局无法安全更新时，AgentWeave 会提示原因。

点击插件可展开文件树并查看或编辑文本文件。保存会修改该 Agent 的原文件并重新扫描。平台列表会直接显示冲突项。展开「重复项」可以查看和勾选重复资源，收起分组会保留勾选。

- **Skill** 检查 `SKILL.md` 的 YAML 元数据、必填的 `name` 和 `description`，以及名称与目录是否一致。[Agent Skills 规范](https://agentskills.io/specification)
- **MCP** 检查 JSON 或 TOML 能否读取，启动命令或 HTTP(S) 服务地址是否有效，以及参数、环境变量和请求头等字段的类型。
- **全局指令** 检查是否为可读取的 UTF-8 Markdown 文本。
- **插件** 检查清单和 AgentWeave 读取的组件，例如声明的 Skills 位置和 MCP 配置文件。

目标的兼容性会在分发预览中再检查。

## 新建本地资源

打开「中央仓库」，在 Skills、MCP 或全局指令页签右上角点击「新建」。保存后可在列表中勾选一项或多项资源，批量分发到多个 Agent。

- **Skill** 填写标识、描述和 Markdown 正文。标识用小写字母、数字和连字符，例如 `code-review`。AgentWeave 会自动生成 `SKILL.md`。
- **MCP** 根据服务提供的方式，填写本地启动命令或远程服务地址。请求头、环境变量可在相应的连接方式中填写。
- **全局指令** 填写名称和 Markdown 正文。分发时会使用目标 Agent 的全局文件名和目录。

也可以通过 [CLI 新建本地资源](../reference/cli.md#新建本地资源)。

## 第一次分发

在中央仓库找到一个 Skill，点「分发」，选择已安装且支持 Skills 的 Agent。先看变更预览，再点「确认并同步」。

如果想让目标的某一整类资源与中央仓库对齐，打开「同步状态」，选择 Agent 后勾选要纳入同步的类别并保存，然后点击「同步到 {Agent}」。执行前查看[同步规则](./sync.md)，了解哪些资源会出现在删除预览中。
